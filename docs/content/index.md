# C++ runtime reflection

A header-only C++26 library for runtime metadata, checked calls, structural binding,
and replaceable implementations. The project is experimental.

| Task | Start here |
| --- | --- |
| Build and run tests | [Setup](getting-started/index.md) |
| Find types, construct objects, and invoke members | [Runtime reflection](getting-started/runtime.md) |
| Call an object through a declaration-only interface | [Typed binding](getting-started/binding.md) |
| Replace methods and properties | [Dynamic dispatch](getting-started/dynamic.md) |
| Keep reference results alive | [Retained references](getting-started/references.md) |
| Subscribe to completed calls | [Observation](getting-started/observation.md) |
| Understand ownership and module boundaries | [Architecture](architecture/index.md) |

Usage code comes from compiled tests. Each example checks its expected result.
